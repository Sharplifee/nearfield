# Nearfield

Finds Bluetooth devices you cannot see, using the iPhone and Apple Watch together.

- iOS + watchOS, SwiftUI, Swift 6 strict concurrency
- Project is generated by XcodeGen from `project.yml` — there is no checked-in `.xcodeproj`
- CI signs and uploads to TestFlight on every push to `main`. No Mac required.

Do not run Xcode automatic signing with `-allowProvisioningUpdates` against this team.
It revokes every certificate whose private key is not in the local keychain, which on
2026-08-14 killed three pipelines at once.
